The Seraph’s Ledger

 

A personal bundle of small quality-of-life tweaks for Vintage Story.



The Seraph’s Ledger gathers a handful of independent conveniences into one mod — a trader-tracking ledger, larger storage containers, inventory shortcuts, automatic enemy loot, a material swatch tool for builders, barrel ingredient portions, a tally board that counts the animals in a pen, a sortable browser for your installed mods, and a few audio/UI tweaks. Every runtime feature can be switched on or off individually from an in-game settings panel, so you can run the whole bundle or just the parts you want.

What it does

 

Mod list browser

Ctrl+Shift+N (rebindable) or .slmods opens a sortable list of every mod you have installed. The game’s own mod manager lists them in file-name order and nothing else; this one sorts by install date, declared game version, available update, load order, load failures, enabled state, author or description, ascending or descending, and highlights the value it sorted by on each row, so the order always has something to read it against. A search box filters on name, mod id, file name, author and description.

  • Enable and disable mods from the list. Each row carries an [enable] / [disable] link — the one part of the game’s mod manager that is reachable from in-game. It takes a restart either way, so a row you changed this session reads [enabled on restart] / [disabled on restart] and the summary line counts how many are waiting.

  • Disabling asks twice, and says what it will cost — the mods that depend on this one and will stop loading with it, a warning if the mod declares itself part of the base game, and a reminder that blocks and items it adds read as unknown in worlds built with it. Enabling takes one click, since nothing is lost that way.

  • Rescan re-reads the mod folders without a restart. Check updates asks the mod database for the newest release of each mod tagged for this game’s version series and flags what you are behind on; a locally built mod that is ahead of anything published says so rather than claiming to be up to date. It is one request per mod, so it waits for the button and keeps its answers for the session.

  • Installing and deleting mods are deliberately left out — those move files the running game is reading. The game also pins the enabled/disabled setting to the mod’s version, so updating a disabled mod brings it back enabled; that is vanilla behaviour, kept as it is.

  • It is a window of its own rather than sort buttons on the vanilla mod manager, because that screen lives in the main menu where no mod code is running at all. The data behind it is reachable from in-game, and that is what the browser reads: the same mod-info and dependency pass the main menu itself runs, on a mod loader of its own, so the live one’s state and the client log are left alone.

 

Ice-Cooled Cellars

Keep your food twice as long by stocking your cellar with ice.

Place blocks of ice (glacier ice, packed glacier ice — anything icy) in a proper cellar and the room chills below the vanilla 5°C cellar floor. The effect starts at 4 ice blocks and maxes out at 10, where the cellar behaves as if it were about −3°C — roughly double the shelf life of a perfect vanilla cellar. Nothing freezes; food just keeps longer.

- Placement is flexible: ice counts whether it's stacked inside the room or lining the walls, floor, or ceiling — wall lining keeps your storage space free.
- Ice walls now actually cool: vanilla treats ice as a non-cooling wall material (like wood!); with this mod, ice walls rate like stone or soil for the cellar bonus.
- Ice melts realistically: instead of vanishing at outdoor-summer speed, cellar ice melts based on the chilled room temperature — the more ice you stock, the colder the room and the slower each block melts. A fully chilled cellar loses roughly one block per ~17 hours of play, faster as the stock dwindles. In winter, cellar ice doesn't melt at all.
- No flooding: ice melting indoors simply vanishes — no water sources left behind in your cellar. Fully buried ice (like the outer layer of a double wall) is insulated and never melts.
- See it working: hover any container in the cellar — the tooltip shows your ice count and chill strength, and the "Stored food perish speed" numbers update to match.

The room must qualify as a vanilla cellar (small, enclosed, no exits). Thresholds, target temperature, and melt rate are tunable in ModConfig/seraphsledger/features.json; the whole feature can be toggled in the in-game settings panel (Ctrl+Shift+L).

Only want this one feature? It also ships on its own as the Ice Cellar mod — same mechanic, none of the rest of the bundle. Running both is safe from Seraph’s Ledger 1.15.2 onward: this mod detects Ice Cellar and hands the feature over, so nothing is applied twice. On 1.15.1 or older that hand-off doesn’t work — update, or switch ice-cooled cellars off here.

Material swatch tool

See a build in a different material before you commit to it. Aim at one corner and run /sw mark, then aim at the opposite corner and mark again — two marks at the same height read as a footprint and the top is taken from the rain map, so a whole building is bracketed without flying up to its roof. The area is highlighted so you can see what you caught. Press Ctrl+Shift+M: the materials found in the selection are on the left, what each can become is on the right with the number of blocks each swap would change. Apply, and Undo if you don’t like it.

  • Every finish of a material moves at once — cobble, bricks, polished, stairs and slabs all follow, and stair facings survive the swap. The choices come from the block registry rather than a built-in list, so modded stone and wood show up on their own and swaps that don’t exist are never offered.

  • Only blocks somebody placed are listed or swapped. Grass, soil, gravel, sand, ore, raw stone, water and plant life stay out of it, so the list holds your build rather than the ground under it — and restyling a wall never repaints the hillside behind it.

  • Chiselled blocks are re-materialed in place, keeping their carving.

  • Blocks holding contents or state — chests, doors — are skipped and reported rather than swapped and emptied.

  • Undo covers your last 25 swaps, newest first, from the dialog or /sw undo.

  • Chat equivalents — /sw list, /sw options [material], /sw swap <from> <to>, /sw unmark. Requires the controlserver privilege.

Only want this one feature? It also ships on its own as the Swatch mod — install it alongside this one and Seraph’s Ledger hands the feature over, the same way Ice Cellar works.

 

Barrel ingredient portions

Barrel recipes are exact ratios, not “up to”. A full 50 L barrel of water wants exactly 50 lime for limewater and exactly 5 oak or acacia logs for weak tannin — tip a whole stack in and vanilla swallows the lot, then matches no recipe at all until you work out how much to pull back out. With this on, the barrel takes what it can use and the remainder stays in your inventory.

  • Every barrel recipe, not a list of a few — the amount is worked out from the recipes themselves, so 50 L of tannin stops at 25 small hides (12 medium, 8 large) and recipes added by other mods are portioned too.

  • However you load it — click, shift-click, ctrl+click move-all, or a hopper feeding the barrel. The slot just stops accepting once it holds enough.

  • An empty barrel is left alone — the liquid inside is what fixes the ratio, so loading the solids first still works exactly as it always did.

 

Animal tally board

A slate chalkboard, hung on a wall like a painting, that keeps count of the animals in its pen. Look at it and the tooltip reads out what’s inside the fence: each species with a breakdown by kind (Hen 15 · Rooster 9 · Chick 3), the eggs sitting in henboxes and how many of those are fertile, and any eggs lying loose on the ground. Crafted from 2 planks and 1 charcoal.

  • It counts the pen, not a circle around itself. The board walks the ground outward the way an animal could: fences, walls, closed gates and closed doors stop it, open doorways don’t. Coops, runs and yards joined to the pen are counted as one, so a single board covers a fence with two coops on it — and a neighbour’s flock on the other side of the fence never lands in your total.

  • It finds gaps in your fence. If that walk escapes and runs 100 blocks out, the pen isn’t closed — the board says so in orange and counts everything within 100 blocks instead. A board that suddenly reads “pen open” means a gate was left open or a rail got broken.

  • Any animal, not just chickens — sheep, goats, pigs and everything else are grouped by species and named the way the game names them (ram, ewe, lamb; hen, rooster, pullet, cockerel, chick). Players, traders and drifters are never counted.

  • Birds where birds actually sit — a hen roosting in a henbox and a chicken pressed up against the fence rail both count.

  • Right-click it to see what it sees — a closed pen has its outline marked for 25 seconds; an open one shows the trail the count followed out, which crosses your fence line exactly at the gap. Hang the board on either face of a wall: if the walk escapes on the side it faces, the board tries the other side.

  • Cheap to run — the count is taken on the server every 10 seconds, and only while somebody is within 64 blocks; players are sent the totals, not the search. Several boards in one pen count on the same beat, so they always agree with each other.

 

Trader ledger

Automatically records every trader whose Buy/Sell window you open — their location, name, type, and full buy/sell lists (prices and stock as of your last visit). Stored per-world; revisiting a trader updates their entry in place.

  • Map waypoints — a color-coded (by type) waypoint is dropped at each trader the first time you visit. .traders wp maps any not yet marked.

  • In-game browser — open with Ctrl+K (rebindable). Search by name, type, or item; sort by type/name/recent; click [show on map] to jump to that trader.

  • Chat — .traders lists everyone; .traders <text> shows full wares for matches; .traders export writes a Markdown summary to the mod data folder.

 

Large storage containers

Bigger variants of the vanilla containers, each crafted from two of the base container in a shapeless grid recipe. They keep the vanilla look, footprint, and sounds.

  • Large Trunk — 100 slots, crafted from 2× Trunk

  • Large Chest — 45 slots, crafted from 2× Chest

  • Large Labeled Chest — 45 slots, crafted from 2× Labeled Chest

  • Large Storage Vessel — 35 slots, crafted from 2× Storage Vessel

  • Large Basket — 21 slots, crafted from 2× Basket

 

Large container rescue

A large container holds more slots than the vanilla block entity defaults to, and that count lives in the block — so a save loaded once without this mod trims every large container it touches to 16 slots and drops the rest for good. No error, no log line, just an emptier trunk. The game does that itself, before any mod gets a say, and it is the same for every mod that widens a container. This feature is the net under it.

  • The mod keeps a copy of each large container’s contents in the savegame’s own mod data, which the game loads and writes back untouched for mods that aren’t installed — so the record survives exactly the thing that destroys the container.

  • When a container comes back from disk short of what the record says it held, the items go straight back in and you get a chat line saying so. That happens only when the shortfall carries the engine’s own fingerprint: nothing left at or past slot 16, where the trimming always cuts, while the record had something there. A container that is merely emptier than the record — which is what your own hand looks like — is never refilled on its own; it is held for you to decide.

  • /sl rescue lists anything held back and /sl rescue 2 puts that one back; /sl forget 2 drops an entry and /sl status says what is on record against what it can see right now. Restoring only ever fills empty slots, so it can add to a container but never overwrite what is in it now.

  • Matching is by contents rather than by slot, so sorting a container is never mistaken for a loss, and the record is refreshed on every world save, in the same pass that writes the chunks.

  • It cannot recover a container that was already trimmed before version 1.25.0 — there was no record to keep.

 

Sort by freshness (Large Storage Vessel)

A vessel full of crocks tells you nothing about which one to open next. The Sort by freshness button under the Large Storage Vessel’s grid lays the vessel out as a larder, in the order you should eat it:

  • Unsealed crocks first, since those spoil at the ordinary rate, then sealed crocks, then empty crocks, then everything else by item.

  • Within each group, whatever goes off soonest comes first — ordered by the same “fresh for” figure the crock’s own tooltip shows, with the seal and the vessel’s (or ice-chilled cellar’s) perish rate already counted in. Rotten contents rise to the top, food that never spoils sinks to the bottom of its group.

  • Part-stacks are merged the game’s own way, so perishables average their freshness instead of one stack quietly inheriting the other’s timer.

  • The sort runs on the server, for the player who has that vessel open, so it’s safe in multiplayer. Hovering the button explains the order; the hover text has its own switch if you’d rather not have it.

 

Crate sweep

One gesture puts every stack of what a crate holds into it, taken from your hotbar and your worn bags. A crate takes one kind of thing and names that kind itself, so a sweep can never put the wrong item in — which makes a crate the one container where “all of this, in there” is safe to ask for. Three ways to ask, each with its own switch:

  • Ctrl + Shift + right-click with an empty hand reads the kind off the crate’s own contents. Vanilla does nothing whatsoever for that gesture, so this fills a gap rather than changing an interaction.

  • Ctrl + Shift + right-click holding the item is vanilla’s “add all items”; the sweep now carries on past the held stack and empties the rest. This one does change a vanilla interaction, so it can be turned off on its own.

  • Shift + middle mouse — the same “move all of one item” binding used on an inventory slot — aimed at a crate sweeps it, so the one shortcut means the same thing whether it is pointed at a slot or at a block.

  • An empty crate names no kind, so a sweep leaves it alone: put the first stack in and the sweep follows it. Retrieve-only crates are never swept into, and when a crate fills up partway through, the leftovers stay in your hotbar rather than in a bag.

 

Inventory quality-of-life

  • Ctrl + left-click any slot in an inventory dialog to dump every non-empty slot of that inventory into the open container(s).

  • Sort button in the player inventory — server-authoritative sort of your worn-bag contents.

  • Trash button in the player inventory — destroys the stack currently held on the cursor.

 

Combat / loot

  • Hostile creatures vanish 2 seconds after death and drop their loot automatically — no knife-harvesting required. Applies to anything in the vanilla hostile spawn group (drifters, locusts, bells, shivers, bowtorn, and hostile animals like wolves, bears, hyenas) plus modded mobs using that group. Drops match a full harvest (scaled by animalLootDropRate for non-mechanical mobs); harvesting the body yourself within the 2 seconds never duplicates loot.

 

Creative inventory

  • The search box is auto-focused when the creative inventory opens — start typing immediately. (While focused, the E key types into the search instead of closing the dialog — close with Escape or the X.)

 

Audio

  • Silenced character voice sounds — both player/seraph voices and the trader greeting.

 

Distance Challenge

  • Distance challenge — HUD travel budget that drains as you walk; can't move at 0. /steps add|set.

Requirements

  • Vintage Story (no specific minimum version pinned; built against current game APIs).

  • No other mod dependencies.

  • Singleplayer or multiplayer. The fast-despawn loot feature is server-side, so on a dedicated server it follows the server’s own config; install the mod on the server for that and the trader/container features to work.

Selecting or deselecting individual features

Press Ctrl+Shift+L (rebindable) or run .slconfig to open the settings panel. It has one switch per runtime feature:

  • Trader ledger

  • Ctrl + click move-all

  • Move all of one item

  • Crate sweep (empty hand)

  • Crate sweep (holding it)

  • Crate sweep by hotkey

  • Sort & Trash buttons

  • Large vessel sort

  • Large vessel sort tooltip

  • Large container rescue

  • Creative search auto-focus

  • Enemy fast-despawn & loot

  • Auto-loot all animals

  • Auto-loot leaves a carcass

  • Large containers

  • Silenced voices

  • Ice-cooled cellars

  • Barrel ingredient portions

  • Animal tally board

  • Material swatch tool

  • Mod list browser

  • Distance challenge

Your choices are saved to ModConfig/seraphsledger/features.json. A restart is required for changes to take effect — these features are wired up at load time (Harmony patches, hotkeys, event handlers), so the panel warns you of this.
